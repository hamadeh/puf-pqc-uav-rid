* 32-Channel RO-PUF with 7-Stage Ring Oscillators
.options post=2

* Load 45nm model
.lib 'ptm45hp.lib' TT

Vdd vdd 0 DC 1.1V

* ---- Subcircuit: 7-Stage Ring Oscillator with Enable ----
* Uses a NAND gate as the first stage for enable control (en=1 oscillates)
.subckt RO7 out en vdd gnd
* NAND2 as first stage (acts as inverter when en=1)
XNAND start in1 en vdd gnd NAND2
* Inverter Stage 1
M1 net2 in1 0 0 NMOS W=1u L=45n
M1p net2 in1 vdd vdd PMOS W=2u L=45n
* Inverter Stage 2
M2 net3 net2 0 0 NMOS W=1u L=45n
M2p net3 net2 vdd vdd PMOS W=2u L=45n
* Inverter Stage 3
M3 net4 net3 0 0 NMOS W=1u L=45n
M3p net4 net3 vdd vdd PMOS W=2u L=45n
* Inverter Stage 4
M4 net5 net4 0 0 NMOS W=1u L=45n
M4p net5 net4 vdd vdd PMOS W=2u L=45n
* Inverter Stage 5
M5 net6 net5 0 0 NMOS W=1u L=45n
M5p net6 net5 vdd vdd PMOS W=2u L=45n
* Inverter Stage 6
M6 net7 net6 0 0 NMOS W=1u L=45n
M6p net7 net6 vdd vdd PMOS W=2u L=45n
* Inverter Stage 7 (Output)
M7 out net7 0 0 NMOS W=1u L=45n
M7p out net7 vdd vdd PMOS W=2u L=45n
* Feedback (weak pull-up for start-up)
Rfb out in1 1k
.ends

* ---- Enable all 32 ROs simultaneously ----
Ven en 0 DC 1.1V

* ---- Optional: 2:1 MUXes to select two ROs (standard architecture) ----
* (In a full implementation, you would use pass-transistor or CMOS MUXes
* to route ro_out_i and ro_out_j to the counters. For simplicity here,
* we measure all frequencies directly via .MEASURE statements.)

* ---- Measure Frequency of EACH Ring Oscillator ----
* Counts rising edges to compute frequency
.Measure Tran T1 Trig V(ro_out1) VAL=0.55V Rise=2 
+                    Targ V(ro_out1) VAL=0.55V Rise=3
.Measure Freq1 Param='1/T1'

.Measure Tran T2 Trig V(ro_out2) VAL=0.55V Rise=2 
+                    Targ V(ro_out2) VAL=0.55V Rise=3
.Measure Freq2 Param='1/T2'

.Measure Tran T3 Trig V(ro_out3) VAL=0.55V Rise=2 
+                    Targ V(ro_out3) VAL=0.55V Rise=3
.Measure Freq3 Param='1/T3'

* ... Repeat .MEASURE statements up to Freq32 ...

* ---- Generate PUF Response Bits ----
* Compare frequencies pairwise (e.g., (RO1 vs RO2), (RO3 vs RO4), ...)
* Response Bit = 1 if Freq_i > Freq_j, else 0.
* You can calculate these manually from the .lis file or use a parametric .MEASURE:
.Measure Resp1 Param='IF(Freq1 > Freq2, 1, 0)'
.Measure Resp2 Param='IF(Freq3 > Freq4, 1, 0)'
... (up to Resp16)

* ---- Simulation Control ----
.tran 0.01n 30n

.end
